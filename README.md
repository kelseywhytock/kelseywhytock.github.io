# Learning Archive

Practice projects from [The Complete Full-Stack Web Development Bootcamp](https://www.udemy.com/course/the-complete-web-development-bootcamp/)
by Dr. Angela Yu (Udemy), which I took to build out my back-end skills in Node.js,
Express, EJS, and REST APIs. It also includes my entry for the
[DEV.to "Glam Up My Markup: Winter Solstice"](https://dev.to/challenges/frontend-2024-12-04) frontend challenge.

Most projects follow the course's guided exercises, and folder names keep the
course's section numbering for reference.

These are kept as a record of ongoing learning. For current work, see my
[profile](https://github.com/kelseywhytock).
